你在准备哪个考试？

选好后，页面上的词汇、练习和考点都会按这个考试显示。之后随时可以在右上角切换，背词进度两边通用。

使用前请先看一下

  • 不需要注册。学习记录只保存在你这台设备的这个浏览器里，清理浏览器数据、用无痕模式或换设备都会丢失。请定期在「设置 → 学习数据」导出备份。
  • 推荐用电脑上的 Edge 浏览器：朗读声音最自然，语音识别在国内一般可以用。不要在微信、QQ 里直接打开，内置浏览器不支持朗读和录音。
  • 听力和口语需要浏览器朗读声音，口语还需要麦克风。手机浏览器对这些功能的支持差异很大，可能用不了。
  • AI 讲解、AI 估分是可选功能，需要在「设置」里填写你自己的 Claude API Key；不填也能使用其他所有功能。
  • 题目、解析和范文都是原创练习题，不是考试真题。发现错误时，在解析页点「这题有问题」，把复制的内容发给邀请你内测的人。

你现在是用手机打开的：背单词、阅读、写作可以正常使用；听力和口语建议用电脑。
