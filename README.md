# 托福雅思备考工作台

面向 2026 新版托福（TOEFL iBT）的备考网页，同时提供雅思词汇，并可以导入课程老师布置的单词。纯静态页面，不需要安装任何东西，也不需要注册账号，用浏览器打开即可。

**在线使用**：https://looffeeuu.github.io/toefl-ielts-prep/

**产品介绍**：[托福雅思备考工作台 · 产品介绍](https://claude.ai/artifact/X1xbT1wKjELevyxXd6xuqM)（第一次用建议先看这篇：功能一览、快速开始、常见问题和反馈方式）

## 给同学的使用说明

- 完整的使用介绍见上面的[产品介绍](https://claude.ai/artifact/X1xbT1wKjELevyxXd6xuqM)，下面是要点
- 直接打开上面的网址就能用。第一次打开时选择托福或雅思，页面上只显示这个考试的内容，之后可以在右上角随时切换。也可以直接打开 https://looffeeuu.github.io/toefl-ielts-prep/#ielts/vocab 或 `#toefl/vocab` 进入对应考试
- 每个人的背词进度和练习记录只保存在自己的浏览器里，互不影响，也不会上传到任何服务器
- 换电脑或换浏览器前，在「设置 → 学习数据」导出备份，到新地方再导入
- 背老师布置的单词：词汇页左栏「我的词表 · 导入老师布置的单词」，粘贴单词或选择 txt / csv 文件。导入后点「只背这个」就会按随机顺序背
- 把词表发给同学：在「我的词表」里点「分享链接」，把链接发出去；对方打开后先预览，确认后保存到他自己的浏览器。也可以点「下载」把词表存成 txt 文件发送
- AI 讲解和批改需要自己的 Claude API Key（在「设置」里填写），不填也能使用其他所有功能

## 内测与反馈

- 右上角可以切换外观：跟随系统、浅色、深色（设置页「外观」里也能改），选择会记住
- 第一次打开时，选择考试的页面下方有「使用前请先看一下」，设置页里也有同样的说明
- 在微信、QQ、微博、支付宝、钉钉、飞书里打开时，页面顶部会提示改用浏览器打开（这些内置浏览器不支持朗读和录音）
- 有学习记录、且超过 7 天没有导出备份时，页面顶部会提醒备份，可以一键导出或推迟 7 天
- 每道题的解析里有「这题有问题」，词条详情里有「词条有误」，写作复盘页有「题目或范文有问题」：点击后自动复制题目信息、你的答案、正确答案、版本号和浏览器信息，测试者粘贴到微信发给你即可；设置页可以「复制环境信息」
- 维护者：发布新版本时修改 `js/beta.js` 里的 `App.VERSION`；如果有问卷或邮箱，把地址填进 `App.FEEDBACK_URL`，提示里会出现「打开反馈页」
- 首次加载约 0.8 MB（压缩后）。8 秒还没加载完会提示可能是网络问题，文件加载失败会直接说明原因

## 已有模块

页面按考试分开：托福有词汇、口语、阅读、听力、写作、考点；雅思有词汇、口语、阅读、听力、写作和考点（雅思考试结构、评分规则、官方资源和各部分考点）。「我的词表」和设置两边共用。

### 词汇
- 词库跟随右上角选择的考试：托福页面用托福词库，雅思页面用雅思词库，本轮词库、测验范围、词库浏览和进度统计都只针对当前考试；两套词库共有的词（约 2,700 个）共用同一张卡片，背过一次两边都算
- **雅思词库**：5,026 词，整理自 ECDICT 中标注为雅思的词条，按词频分为高频、次高频、中频、低频，每 200 词一组。和托福重复的词带托福词库里的例句与同义替换
- **我的词表**（导入自定义词表）：
  - 粘贴文字或上传 txt / csv 文件，每行一个词，可以带词性和中文释义（如 `abandon 放弃`、`1. abandon v. 放弃`），也可以从 Excel 复制两列直接粘贴，或者只给单词。csv 文件 UTF-8 和 GBK 编码都能识别
  - 导入前先预览：内置词库里有的词直接使用词库的释义、例句和背词进度；其他词用离线词典（约 1.9 万词，打开导入窗口时才加载）补全释义；仍然查不到的可以手动填写，或者用 AI 补全。词表里自带的释义和词库不同时，卡片上会额外显示「词表释义」
  - 导入后可以「只背这个」（随机顺序），也可以在「本轮词库」里和内置词表一起勾选；测验和词库浏览里也能选到
  - 词表可以重命名、删除、下载成 txt，或生成分享链接（词表压缩后放在网址里，不经过服务器）；词表随背词进度一起导出备份
- 托福共 6,973 词，分为五组：
  - **核心精编** 350 词：按阅读常考话题分为 10 组，每个词带中文释义、同义替换和学术例句
  - **高频 / 次高频 / 中频 / 低频**：6,623 词，整理自开源词典 ECDICT 中标注为托福的词条，按词频排序，每 200 词一组，带音标和中文释义。其中 3,850 个学术常用词另外补写了同义替换和例句（高频、次高频和中频的学术词基本覆盖，低频补写了 376 个偏学术的词）
- 多词性的词（vt. 和 vi. 也分开算）每个常用词性都有一句例句，卡片上按词性分行显示释义和例句，目前共 718 个词
- 托福和雅思词库的 9,075 个词全部有例句：原来只有释义的 4,875 个词由 `js/words-ex-*.js` 补上（原创例句，只补例句、不改释义）
- 背词卡片在单词旁边用灰色小字显示构词（前缀 / 词根 / 后缀），翻开答案后再显示每部分的意思；只在拆得可靠时显示（`js/word-parts.js`）
- 「本轮设置」里可以多选本轮要背的词表（整组或单个 200 词词表），新词可按词表顺序或随机出现（随机顺序固定，点「重新打乱」才会变）
- 新词默认跳过中考词汇（可以在学习设置里改成同时跳过高考词汇，或不跳过）
- 间隔重复背词：翻卡后选「不认识 / 模糊 / 认识 / 太简单」，自动安排下次复习时间
- 已经会的词可以直接点卡片下方的「这个词我已经掌握了」（快捷键 M），不用等复习间隔累积到 21 天；新词这样跳过不占当天的新词名额，60 天后再抽查一次，可以撤销。词详情里也能标为已掌握或取消
- **分析**标签页：已学、已掌握（含手动）、学习中、近 7 天复习记住率、测验正确率，以及经常忘记的词、经常拼错的词（附你写错的拼法）、容易混淆的词、还不稳的词、做题时查过的词，每组可以一键「集中复习」；词详情里也会显示这个词的个人记录
- 做题后的复盘：托福阅读、托福听力原文，雅思阅读和听力交卷后的原文，以及托福和雅思写作的范文里，词库单词（含「我的词表」）用虚线标出，正在学的词用实线标出，点击即可查看释义、加入背词
- 三种测验：看词选义、同义替换（仿托福阅读词汇题）、听写拼写；答错的词自动回到复习队列。选择题先选中、再按 Enter（或再点一次）确认，避免手滑；拼写题可以「提示一个字母」或「忘记了，看答案」
- 快捷键：空格翻卡，1–4 打分，P 发音

### 口语（新版题型）
- **听后复述 Listen and Repeat**：6 套场景，每套 7 句由短到长；每句只播放一次，提示音后 8–12 秒复述。练完后逐词对比，标出漏掉的词并给出完整度
- **模拟面试 Take an Interview**：8 个话题，每个 4 题，无准备时间，每题 45 秒。练完后可以回放录音、修改识别文字、查看词数和语速，每题附参考思路
- 录音只保存在当前页面里，关掉页面就没有了

### 托福模考（考场模式）
- 导航栏「模考」：可以考完整的四个部分（阅读 → 听力 → 写作 → 口语，约 75 分钟），也可以只考其中一部分
- 仿照机考的流程和界面：全屏进行，顶部状态栏显示部分、模块、题号和倒计时（可以 Hide Time），一屏一题
  - 阅读：两个自适应模块各 12 分钟，模块内可以 Back / Next，Review 页面查看哪些题没答并跳转
  - 听力：两个自适应模块，录音只播放一次，每题有作答时限，只能往后
  - 写作：组句 10 题（6 分 50 秒）、写邮件（7 分钟）、学术讨论（10 分钟），编辑框有 Cut / Paste / Undo / Redo 和隐藏字数
  - 口语：听后复述 7 句、模拟面试 4 题，提示音后自动录音
- 结束后显示各部分结果，可以逐题看解析、回放口语录音；阅读、听力、组句结果计入各模块的题型统计
- 界面是本站自己设计的，不使用 ETS 的标志和品牌样式；新版托福没有公开的分数换算，这里只给正确率

### 雅思模考（考场模式）
- 雅思导航栏「模考」：完整模考按 听力 → 阅读 → 写作 的顺序连续进行（约 2 小时 30 分钟），也可以只考其中一部分；口语在「口语」里做完整模拟
- 仿照雅思机考界面：全屏，顶部倒计时（可隐藏）、A−/A+ 调字号、一键切换深浅色
  - 底部按 Part 排列的题号导航：已答的题会标出，点题号跳到对应的题，勾选 Review 标记待检查的题，左右箭头逐题移动
  - 阅读：左文右题，中间分隔条可以拖动；选中文章里的文字可以高亮，切换 Part 后仍然保留；60 分钟到时自动交卷
  - 听力：每部分 30 秒看题时间，录音只播放一次，可以边听边答、查看其他 Part；四部分结束后 2 分钟检查时间
  - 写作：Task 1 与 Task 2 共用 60 分钟，底部切换并显示字数，左边题目和图表、右边作答
- 结束后显示听力、阅读的大致分数段和逐题解析，写作的自动检查和范文；结果计入雅思各模块的记录

### 剑桥真题答题卡
- 雅思导航栏「真题」：对照自己手上的《剑桥雅思》1–21 做题。选书、套题和部分（听力 / 学术类阅读 / 培训类阅读），在 40 格答题卡上计时填写答案
- 交卷后录入书上的答案（可以一次粘贴全部，多个可接受答案用 / 分开，题型可按范围批量设置），自动判分；听力和学术类阅读按参考分数线换算分数段
- 判断题可以写 T / F / NG、Y / N / NG；同一套题再做时自动判分
- 错题可以选错因（拼写、超字数、没认出同义替换、没定位到等），首页汇总常见错因和各题型正确率，并用表格显示 21 本书每套题的完成情况
- **本站不收录也不分发书中的文章、录音、题目或答案**，需要用户自己有纸质书或正版电子版；录入的答案只保存在用户自己的浏览器里

### 雅思口语
- **Part 1 日常问答**：12 个话题，每个 4 题（学习或工作、家乡、住所三个是考试开头常问的身份类话题）。考官提问只有声音，每题最多录 40 秒，说完按空格进入下一题
- **Part 2 话题卡**：10 张。1 分钟准备时间，旁边可以记笔记（陈述时笔记仍然可见）；然后最多讲 2 分钟，进度条上标出 1 分钟的位置；讲完有一个简短追问
- **Part 3 深入讨论**：10 组，每组 4 题，接对应的 Part 2 话题，每题最多 75 秒
- **完整模拟**：按真实顺序随机抽题，Part 1 先问一个身份类话题 4 题、再问两个其他话题各 3 题，然后 Part 2 和同一主题的 Part 3，共 16 题，约 12–15 分钟
- 练完按部分分组回放录音，显示时长、词数、语速和填充词，可以修改识别文字；Part 2 不到 1 分钟会提示；每组附中文答题思路
- 填写 API Key 后可以让 Claude 按雅思口语评分标准估分（流利与连贯、词汇、语法三项；发音无法从文字判断），逐题点评并给出改进版回答
- 题目和考官的话都是原创的，不是考试真题或网传题库

### 雅思阅读（学术类）
- 6 篇原创文章、80 题，按难度分三档（对应考试中的第 1、2、3 篇）。每篇约 450–560 词，比真题（约 700–900 词）短
- 题型：判断（True / False / Not Given、Yes / No / Not Given）、段落标题、段落信息配对、人物观点配对、句子结尾配对、摘要和笔记填空（限制字数）、单选、简答
- **单篇练习**：建议 20 分钟，超时继续计时但不强制交卷
- **完整模拟**：每档各抽一篇，题号 1–40 连续，可以在三篇之间切换，60 分钟到时自动交卷
- 交卷后逐题显示你的答案、正确答案和中文解析（指出依据在哪一段）；填空超出字数限制按错误计算

### 雅思听力
- 两套原创练习、每套 4 个部分共 40 题：Part 1 日常对话（表格填空）、Part 2 日常独白（单选、配对）、Part 3 学术讨论（单选、配对）、Part 4 学术讲座（笔记填空）
- 录音由浏览器朗读，每个说话人用不同的声音；每部分开头有旁白介绍
- **单个部分练习**：30 秒看题时间（可以提前开始）→ 播放录音，边听边作答 → 提交。题号和真实考试一致（Part 3 是 21–30 题）
- **整套模拟**：四个部分连续进行，最后有 2 分钟检查时间，时间到自动交卷
- 录音只播放一次；做完后可以看原文、点句子重听、播放全文
- 交卷后按 British Council 公布的参考分数线（答对 16 / 23 / 30 / 35 题约对应 5 / 6 / 7 / 8 分；阅读为 15 / 23 / 30 / 35）给出大致分数段，题目没有经过难度校准，只作参考

### 雅思写作（学术类）
- **Task 1 图表描述**：6 道，覆盖折线图、柱状图、饼图、表格和流程图，至少 150 词、建议 20 分钟。图表用 SVG 画出，带图例、直接标签和可展开的数据表；数据是虚构的
- **Task 2 议论文**：8 道，覆盖同意与否、讨论双方观点、原因与对策、利弊比较、双问题五种题型，至少 250 词、建议 40 分钟
- **完整模拟**：随机抽一道 Task 1 和一道 Task 2，60 分钟，可以在两篇之间切换
- 写作时实时显示字数和最低要求；没交卷的草稿保存在本机；可以关闭限时
- 交卷后自动检查：字数、概述（Task 1）、是否加入个人观点（Task 1）、观点和结论（Task 2）、举例、分段、照抄题目、连接词、过长句子、重复用词；附写作要点、范文和常用句型
- 填写 API Key 后可以让 Claude 按雅思写作四项评分标准估分（Task 1 会把图表数据一起发给 AI），逐句改错并给出修改版

### 阅读（新版题型）
- **补全单词 Complete the Words**：10 篇学术短文，第一句完整，之后每隔一个词缺后半部分字母，共 10 空
- **日常阅读 Read in Daily Life**：10 篇邮件、通知、告示，每篇 2–3 题，考目的、细节、语气和推断
- **学术文章 Read an Academic Passage**：6 篇，每篇 5 题，覆盖主旨、细节、词汇、推断、作者意图、否定事实和文章结构
- 每道选择题都有中文解析；首页按题型统计正确率，帮你找出薄弱题型
- **完整模拟**：两个模块，每模块 4 个任务、限时 12 分钟。第二模块根据第一模块的正确率（60% 为界）切换到提高或基础难度
- 文章里出现词库单词时会用虚线标出，点击可以查看释义、加入当天背词（模拟作答时不标出）

### 听力（新版题型）
- **听后选回应 Listen and Choose a Response**：4 套共 40 句。只听一句话，从四个文字选项中选最自然的回应，常考间接回答、委婉拒绝、建议句型和重复用词陷阱
- **对话 Listen to a Conversation**：12 段校园对话，每段 2 题
- **通知 Listen to an Announcement**：10 则校园广播和课堂通知，每则 2 题
- **学术讲座 Listen to an Academic Talk**：8 段（天文、环境、生物、艺术史、经济、心理、地质、语言学），每段约 185–220 词、4 题，考主旨、细节、说话意图、推断、组织结构和态度
- 音频由浏览器朗读，按句播放；对话中男女说话人自动用不同的声音（只有一种声音时用音高区分）。和考试一样只播放一次，可以边听边记笔记；单项练习可以在首页打开「允许重听」
- 答完显示原文和逐题中文解析，点原文里任意一句可以重听；原文里的词库单词可以点击查看
- **完整模拟**：两个模块，每模块 4 句选回应、1 段对话、1 则通知、1 段讲座，共 12 题。第二模块根据第一模块的正确率（60% 为界）切换难度。听完后限时作答（选回应每题 20 秒，其他每题 35 秒，本站设定），不能返回
- 首页按题型统计正确率

### 写作（新版题型）
- **组句 Build a Sentence**：6 套共 60 题。先读 A 说的话，再用词块拼出 B 的回答；词块里有干扰项，部分词块已固定。每题全对才得分，答完显示正确句子和语法提示（间接疑问句语序、助动词后接原形等）。每套限时 6 分 50 秒（备考机构给出的时长）
- **写邮件 Write an Email**：8 题，限时 7 分钟，建议 100–150 词
- **学术讨论 Academic Discussion**：8 题，限时 10 分钟，至少 100 词
- 交卷后自动检查字数、称呼和结尾（邮件）、是否点名回应同学和举例（讨论）、连接词、过长句子和重复用词；每题附范文和常用句型；填写 API Key 后可以让 Claude 估分并逐句改错
- 写到一半退出，草稿会保留在本机，下次打开同一题时自动恢复；可以关闭限时模式

### 考点地图
- 新版考试结构（各部分题型、题量、时长）和 1–6 分制计分方式，数据来自 ETS 官网
- ETS 官方资源链接：备考总页、TestReady 与官方样题、考试内容说明、考试规格 PDF、分数说明，以及中国考区报名网站
- 阅读、听力、写作、口语每种题型的考点和常见陷阱
- 按考点统计个人正确率：阅读各题型、听力各题型、组句的 10 个语法考点（间接疑问句语序、时态、被动语态等）、复述完整度
- 本站不收录 ETS 真题或网传「机经」：真实考题受版权保护且未公开发布

## 打开方式

- **线上**：用 GitHub Pages 地址打开（仓库 Settings → Pages 里能看到）
- **本地**：麦克风只能在 https 或 localhost 下使用，直接双击 `index.html` 打不开录音。在本目录运行：

  ```bash
  python -m http.server 8000
  ```

  然后访问 http://localhost:8000

## 浏览器建议

推荐 **Microsoft Edge**：
- 朗读题目时可以选择 “Online (Natural)” 声音，最接近真人
- 语音识别在国内一般可以使用；Chrome 的语音识别需要访问 Google 服务，在国内通常连不上。识别失败时，录音和回放不受影响，复述题可以对照原句自评

## AI 讲解与口语点评（可选）

在「设置」里填写自己的 Claude API Key 后：
- 背词卡片上出现「AI 讲解」：词根词缀、记忆方法、搭配、例句
- 托福模拟面试和雅思口语练完后可以生成估分、逐题点评和示范回答
- 写邮件和学术讨论交卷后可以生成估分、改错和修改版

Key 只保存在你自己浏览器的 localStorage 里，请求从浏览器直接发到设置中的 API 地址，不经过任何其他服务器。使用模型为 `claude-opus-5-5`，并开启了服务端兜底（`fallbacks: "default"`），如果请求被拒会自动换用其他模型重试。

## 数据与备份

背词进度、自定义词表，以及托福和雅思各部分的练习记录保存在浏览器的 localStorage 中，只存在于当前这台电脑的当前浏览器。换设备前，在「设置 → 学习数据」导出备份，再到新设备导入。
