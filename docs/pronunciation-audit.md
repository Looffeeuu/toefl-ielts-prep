# 音标核对记录（2026-11-16）

本轮扫描全部 9,075 个内置词条，清单见 [pronunciation-audit.json](pronunciation-audit.json)。30 个已对照剑桥词典核对，9,045 个尚未逐词核对，不能宣称全库音标准确。

`js/pronunciation-reviews.js` 保存 34 词的核对日期、剑桥发音页链接、适用词性或含义、英音和美音。separate、read、bass、use 不在内置词库，导入自定义词表时也可使用其核对音标。

来源为剑桥自身发音页的网页索引内容；直接访问部分页面返回 403。音标保留重音、音节分隔点和英音上标 ʳ；中文适用范围由本项目概括。列表区分主要读法，不保证收录所有方言或语流变体。protest 的美音动词另有首音节重读变体，在卡片中注明。

核心 `CORE_PHON` 位于 `words-ext.js`，扩展、雅思词表和导入查询也带有历史音标。ECDICT 来源声明不能替代逐词核对，原始版本和每条音标的权威出处尚不完整。

未核对条目中：334 个缺失音标；4,720 个含西里尔字母（如 ә）；7,552 个含旧式重音或长音记号。候选可重叠，符号差异不等于读音错误。未用字符替换或自动拼读冒充词典音标。

卡片、词库和详情统一显示核对音标；同形异音按词性或含义分行。卡片翻面前隐藏中文义项提示。其余标注“原词库音标 · 尚未核对”，并提供查词典链接。扬声器仍为浏览器语音合成，非剑桥录音，尚未按义项选择发音；可通过出处链接听词典示范音。

运行 `node tools/check_pronunciations.js --write` 可重新生成清单。检查覆盖加载顺序、修订应用、英美音字段、同形异音、输出转义与答案隐藏，不会自动判定未核对音标是否正确。标注说明见 [剑桥 Phonetic symbols](https://dictionary.cambridge.org/help/phonetics.html)。
